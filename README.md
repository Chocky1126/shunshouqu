# 顺手取 v1.7.5 · 安卓取件助手

中文、离线的个人取件码管理工具，支持 Android 8.0 及以上的 ARM64 设备。奶油底色、棕色像素边框、橙色主按钮，数据保存在手机本地。

覆盖此前交付版本安装即可，**不要先卸载或清除应用数据**。包名 `cn.pickup.pocket`，versionCode 31，数据库保持 v5。

## v1.7.5 首页底部按钮

按选定的第一版设计，将录入按钮和箭头合为一个橙色像素边框，中间用细线区分点击区域；一键取出保留浅色按钮。两个按钮统一高度和间距，保持原有操作。

## v1.7.4 弹出菜单宽度

首页左下角录入菜单及右上角菜单按最长菜单项的文字、图标和间距适配宽度，随系统字号调整，并限制在屏幕内。

## v1.7.3 更多设置排序

更多设置按“首页显示 → 放置天数 → 桌面小部件 → 使用引导”排列，保留橙色按钮样式和原有操作。

“清空已取件”“使用引导”“添加到桌面”统一使用“保存提醒天数”同款样式：橙色底、白色文字、棕色像素边框。数据库和原有操作保持不变。

“清空已取件”“使用引导”“添加到桌面”三个按钮改为深棕色底、奶油色文字，保留像素边框和原有操作。数据库与引导版本不变。

## 使用

完整操作说明见 [使用指南](docs/user-guide.md)。

1. 右上角菜单 → 站点设置：设置名称、图标和格式。一个 `x` 表示一位数字，多种格式每行一种；可拖动或用箭头调整站点顺序。
2. 点录入按钮添加一条；点上箭头选择批量、截图或短信。核对后勾选保存。特殊格式使用右上角菜单 → 手动录入，自行指定站点。短信文字或图片也可分享给顺手取。
3. 首页按站点分组，站点内按每段数字升序排列，保留前导零。左滑或点方框标记已取；一键取出会标记全部待取。点站点标题进入大字取件模式，长按取件码可编辑。
4. 右上角菜单 → 已取件：恢复最近 7 天的记录，也可清空历史。清空不可恢复。
5. 更多设置：调整字号、行距和放置天数提示，添加桌面小部件，重看使用引导。

## 桌面小部件

4×4 标准 Android 小部件最多显示 6 条取件码，从顶部开始排列；缩小时减少可见行，并提示剩余件数。点方框完成一件，点一键取出完成全部待取。录入、取件、编辑、恢复和站点调整后自动刷新。

更多设置 → 添加到桌面：先显示应用内示例，再请求系统确认。也可在桌面的普通“小部件/插件”列表中找到顺手取。部分桌面可能不支持自动添加；OPPO 平台专有“全部卡片”与标准 Android 小部件并非同一入口。

## 数据和识别规则

默认站点格式为 `x-x-xxxx`、`x-x-xxx / xx-x-xxx`、`xxxxxx`。站点名称 1–30 字符，每站最多 10 种格式，每条最多 32 字符；不同站点不能使用相同格式。修改格式只影响以后录入；有待取件的站点需先处理记录才能删除。

手动录入和编辑接受 1–32 字符的数字及连字符结构，支持全角数字和常见连字符规范化。批量识别只匹配完整数字片段，不截取手机号或长单号的一部分。相同格式的其他数字仍可能成为候选，请核对；修改原文后需重新识别。每次最多 200 个候选，原文最多 10 万字符。截图一次最多选择 10 张，使用内置模型在本机识别，无需下载模型。

扫描短信由用户主动触发并申请 `READ_SMS`，只查询近 72 小时收件箱，最多检查最新 500 条，过滤待取及最近 7 天已取码。只保留用户确认保存的取件码，不保存短信全文。此权限受 Android 和安装来源限制，部分系统可能拒绝授予；可以改用分享、系统粘贴或截图录入。用户已报告 OPPO Find X8 / ColorOS 16 短信扫描实机测试正常。

没有账号、云同步、备份、定时通知或后台自动扫描。不申请网络、相机、通知、开机广播或全盘存储权限；图片通过系统文件选择器读取。历史保留 7 个实际经过的 24 小时，过期历史读取时清理。放置天数按本地日期计算，阈值 1–30 天，仅在界面显示。卸载或清除数据会删除本机记录。

## 构建与验证

需要 JDK 17、SDK Platform 35 / Build Tools 35.0.0；Gradle 8.11.1 Wrapper、AGP 8.9.2 已配置。Android Studio 打开本目录，或配置本机 `ANDROID_HOME` 后执行：

```sh
./gradlew testDebugUnitTest testReleaseUnitTest lintRelease assembleRelease
```

Windows 使用 `gradlew.bat`。首次构建需要联网下载依赖，应用运行不需要网络。APK 位于 `app/build/outputs/apk/release/app-release.apk`。

交付 APK 使用既有调试证书签名，构建类型为不可调试 release，以支持覆盖旧交付包。其他电脑默认调试证书不同，重新构建的包可能不能覆盖已安装版本；源码不包含签名私钥，应用商店发布应另行配置正式签名。

```sh
./gradlew connectedDebugAndroidTest
```

设备测试会清空本应用的测试数据，仅应在专用模拟器执行，不能在存有真实取件码的手机上运行。测试涵盖迁移、排序、批量解析、短信过滤、图片识别、分享、编辑、历史、大字取件、菜单、显示设置、引导和小部件。v1.7.0 正式版验证证据及范围见 [交付说明](DELIVERY.md)，v1.7.5 首页操作区更新见 [更新说明](docs/releases/v1.7.5.md)。
