# 顺手取 v1.6.12 · 安卓取件助手

中文、离线的个人快递取件码管理工具，支持 Android 8.0 及以上。直接覆盖此前交付版本安装，自动迁移数据库；不要先卸载或清除数据。

## 沿用复古像素设计

采用用户确认的「风格探索 2：像素口袋」：奶油底色、棕色阶梯边框、橙色主按钮、像素包裹和站点插画。标题使用精简的中文像素字库，取件码使用清晰大字，保留完整前导零。

首页显示站点分组与取件码；「粘贴录入」「截图识别」「已取件」「站点设置」「更多设置」集中在右上角菜单。取件码仍按各段数字升序排列，支持左滑或方框按钮标记已取、历史恢复及长按编辑。仅逾期记录显示放置天数，常规记录减少附加文字。主界面不展示格式规则。

录入、历史、取件模式、站点设置和便捷设置统一暖色与像素边框。启动图标也使用新配色。保留原生滚动、无障碍按钮描述、系统字体缩放与关闭动画设置。

沿用 v1.5.0 的 ARM64 精简包、剪贴板主动/自动识别、分享和多图本地识别。此前已删除的备份与每日通知不恢复，数据库为 v5。覆盖安装保留本地数据。

## 日常使用

1. 在右上角菜单的「站点设置」新增、编辑或删除站点。每个 `x` 表示一位数字，`-` 表示连字符；多种格式每行一种。例如 `x-x-xxx` 和 `xx-x-xxx`。
2. 选择「录入取件码」输入一条；格式特殊时点「手动选站点」。长按清单中的取件码可以修改代码和归属，保留原录入时间。
3. 在右上角菜单选择「粘贴录入」，粘贴多条短信或多个取件码，点击识别，核对并勾选后保存。重复待取码会标出并跳过；修改原文后必须重新识别。每次最多 200 个候选，原文最多 10 万字符。
4. 选择「截图识别」，通过系统选择器选择一张或多张图片，应用在本机识别，然后进入相同的批量核对页。识别结果可能不准确，不会自动保存；可修改文字后重新识别。
5. 点击一个有待取件的站点标题，进入大字取件模式。按「已取，查看下一件」逐条取件，或「跳过，稍后取」。可勾选屏幕常亮，退出或切到后台后会解除。
6. 清单左滑或点「已取件」均进入历史，可从右上角菜单「已取件」恢复最近 7 天的记录。原站点已删除时可选择现有站点恢复。可点击「清空已取件」，核对数量后确认清空；此操作不可恢复。
7. 在站点设置长按站点拖到目标位置，或点上下箭头，调整取件路线顺序。各站点内仍按每段数字升序排列，前导零保持原样；空站点默认折叠，点击可展开。
8. 清单显示「今天录入／已放 N 天」，默认满 3 天突出提示；「更多设置」中可设 1–30 天。该标记仅在应用内显示，不发送通知。

## 规则和数据

默认站点格式为 `x-x-xxxx`、`x-x-xxx / xx-x-xxx`、`xxxxxx`。站点名称 1–30 字符，每站最多 10 种格式、每条最多 32 字符；不同站点不能使用相同格式。

手动录入和编辑也只接受 1–32 字符的数字及分隔连字符结构。前导零保留，支持全角数字和常见连字符规范化。修改站点格式只影响以后录入，已有记录归属保持不变。删除站点前要先处理该站点的待取件；历史记录保留原站点名称。

批量提取仅匹配完整数字片段，不从手机号、长单号中截取局部数字。具有相同格式的其他数字仍可能成为候选，请核对。截图不清晰、特殊字体或字符间距可能影响识别。

数据只保存在本机 SQLite，没有账号或云同步。不申请通知和开机广播权限。不申请短信、网络、相机或全盘存储权限；选择图片使用系统文件选择器。依赖声明了应用内部签名权限用于非导出接收器，用户无需授权。7 天按实际经过的 24 小时计算，过期历史在读取时清理。卸载/清除应用数据会删除记录。

## 开发构建

- JDK 17
- Android SDK Platform 35、Build Tools 35.0.0；minSdk 26
- Gradle 8.11.1（已包含 Wrapper）和 AGP 8.9.2
- 内置 ML Kit 中文文字识别 16.0.1，安装包包含识别模型，首次识别无需下载

Android Studio 打开本目录，安装 SDK 35 并选择 JDK 17；或在本地 `local.properties` 设置实际 `sdk.dir`：

```sh
./gradlew testDebugUnitTest lintRelease assembleRelease
```

Windows 使用 `gradlew.bat`。首次构建需要联网下载依赖；应用使用不需要网络。正式交付包由 `assembleRelease` 构建，位于 `app/build/outputs/apk/release/app-release.apk`。

交付 APK 使用既有调试证书签名，但构建类型为不可调试的 release，以便覆盖旧版并保留数据。不同电脑默认调试证书可能不同，不能直接互相覆盖安装；应用商店发布需要另行配置正式签名。源码不包含本机 SDK 路径或签名私钥。

## 源码入口

- `ImportPayload.java`、`ShareActivity.java`：外部分享校验与只读图片授权转交
- `ClipboardImport.java`：前台剪贴板过滤与去重
- `LegacyCleanup.java`：一次性取消旧版提醒，不创建新定时任务
- `CodeAppearance.java`：首页字号、行距和本机偏好
- `Onboarding.java`：首次安装判定和使用引导状态
- `AppStyle.java`：公共配色、按钮、输入框、图标、弹窗和轻量动画
- `MainActivity.java`：主页、站点管理、站点图标和滑动取件
- `FeaturesActivity.java`：批量、截图、取件模式、历史、编辑页面
- `StationIcons.java`：内置站点图标的稳定键、名称和资源映射
- `ParcelStore.java`：SQLite v5、事务、历史、旧版迁移和小部件刷新通知
- `CodeRules.java`、`BatchParser.java`：规范化、完整格式匹配、数值排序和批量提取
- `ScreenshotRecognizer.java`：本地模型、尺寸受限的图片解码和异步识别
- `ParcelAge.java`：按本地日历计算放置天数
- `PickupWidget.java`、`WidgetSupport.java`：4×4 桌面小部件、完成操作和添加入口
- `docs/superpowers`：历史设计与开发记录
