# v1.7.11-rc1 候选版：站点设置

此版本用于验证站点设置改版，未发布 GitHub 正式 Release。版本号 `1.7.11-rc1`，versionCode `37`。原正式版为 v1.7.10。

## 本次改动

- 独立站点设置页面，卡片展示图标、名称、待取数量和格式；整张卡片可编辑。新增和保存按钮固定在底部，只有中间内容滚动。
- 输入完整示例码生成格式，支持全角数字和常见横线；保留已有格式，不重复添加。
- 每种格式独立一行，带实时示例和删除按钮；可增加到 10 种。
- 保存前显示冲突站点名称，错误格式、重复格式或无效名称不能保存；可输入取件码测试匹配，不会录入。
- 默认隐藏排序控件，点“调整顺序”后可长按手柄拖动或使用上下箭头，点“完成排序”退出。
- 编辑草稿在旋转后保留；返回不保存。占有待取件的站点仍不能删除，已取历史保留。
- 更新应用内和文档中的站点设置引导。
- 修复覆盖升级后系统小部件预览已清除、旧标记仍在时跳过重新生成的问题。

## 实机确认

直接覆盖安装，不要先卸载或清除应用数据。

1. 原站点、格式、图标、排序、待取件和已取历史是否保留。
2. 示例生成、增加/删除格式、匹配测试和冲突提示是否符合预期。
3. 拖动及箭头排序，返回主页后的顺序是否正确。
4. 小屏和大字体时，中间可滚动、底部按钮不被遮挡。

包名、签名和数据库版本保持原样。真实 ColorOS 16 的显示和触摸体验仍需手机确认。
