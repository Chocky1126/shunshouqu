# 顺手取 v1.8.0 正式版

站点设置更容易上手：点击卡片编辑名称、图标和格式；输入一个取件码即可生成格式，核对示例与匹配结果后保存。

## 本次更新

- 独立站点设置页面，卡片显示图标、名称、待取数量和格式。新增与保存按钮固定底部，只滚动中间内容。
- 示例码生成格式，支持全角数字及常见横线；追加到原有格式，不重复添加。
- 格式逐行管理，实时显示示例，每站最多 10 种。错误、重复和跨站冲突会在保存前提示。
- 输入取件码测试匹配，不会新增记录。编辑草稿在旋转后保留，返回不保存。
- 点“调整顺序”进入排序模式，长按手柄拖动或点上下箭头，点“完成排序”收起控件。
- 修复新增与编辑站点页面的图标和文字没有居中对齐的问题。
- 更新站点使用引导；修复覆盖升级后系统小部件预览缺失时不能重新生成的问题。

修改站点格式保留已有取件码。仍有待取件的站点不能删除；已取历史保留。原有短信扫描、截图识别、分享、批量录入、历史恢复与桌面小部件保持可用。

## 安装

下载 `Shunshouqu-v1.8.0-arm64.apk`，直接覆盖安装。**不要先卸载或清除应用数据。**

Android 8.0 及以上，ARM64；包名 `cn.pickup.pocket`，versionCode 38，数据库 v5，签名沿用原版本。

验证结果与限制见仓库 `DELIVERY.md`；完整操作见 `docs/user-guide.md`。
