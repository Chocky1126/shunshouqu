# 顺手取 v1.7.0 正式版

## 本次更新

- 修正“更多设置 → 添加到桌面”的系统确认预览：添加请求携带固定尺寸、完整内容的预览。桌面插件列表继续提供静态图、布局及 Android 15 生成预览。
- “手动指定站点录入”改名为“手动录入”，移到首页右上角菜单。
- 统一页面、弹窗、输入框、下拉框与小部件的奶油底色、棕色边框及橙色主按钮。
- 按最终入口更新五页精简引导，新安装或升级自动展示一次，可在更多设置重看。

## 一并正式发布的功能

相较上个公开正式版 v1.6.12，本版同时包含近期候选版中已加入的功能：

- 首页、小部件一键取出全部待取码；单件方框和左滑取件保留。
- 首页底部两个按钮，录入按钮旁上箭头提供批量、截图、短信入口，取消按钮长按录入。
- 主动扫描近 72 小时短信，核对后保存，过滤已有和最近 7 天已取码。
- 移除应用剪贴板自动识别及主动读取按钮，保留输入框系统粘贴。
- 4×4 小部件最多 6 条，缩小时减少显示行并提示剩余数量；取件后立即补位。

## 安装与数据

下载 `Shunshouqu-v1.7.0-arm64.apk` 覆盖安装，**不要先卸载或清除应用数据**。包名 `cn.pickup.pocket`，versionCode 26，Android 8.0 及以上 ARM64，数据库 v5；沿用既有签名，保留取件码、已取历史、站点、图标、顺序、格式和显示偏好。

短信扫描需用户主动授权，部分系统或安装来源可能限制 `READ_SMS`；其他录入方式仍可用。只保存确认的取件码，不保存短信全文；没有网络上传或后台扫描。

## 说明

系统卡片的边框、文字与确认按钮外观由手机桌面控制。此版通过 Android 15 模拟器验证预览传递和显示；OPPO Find X8 / ColorOS 16 的最终系统确认效果仍需实机检查。应用内界面与小部件使用统一暖色。

使用说明见 `Shunshouqu-v1.7.0-user-guide.md`，详细验证范围见源码内 `DELIVERY.md`。APK、源码、说明和截图的 SHA-256 见 `SHA256SUMS-v1.7.0.txt`。
