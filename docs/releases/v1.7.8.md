# 顺手取 v1.7.8 菜单层次与帮助入口

首页两个弹出菜单的棕色像素边框恢复为站点卡片的相同绘制参数，保留奶油底、分隔线、入口尖角及内容居中。为菜单显式提供不透明阴影轮廓，将原生浮层高度从 3dp 调整到 10dp，增强与主页的区分。

更多设置保持原顺序，在桌面小部件之后增加独立“帮助”区域，注明“查看顺手取的完整使用引导。”，避免将引导误认成小部件说明。仍通过原按钮打开完整五页引导。

包名 `cn.pickup.pocket`，versionCode 34，数据库 v5、引导版本和签名保持不变。不要先卸载或清除应用数据，直接覆盖安装。

验证：13 项菜单和使用引导回归测试通过；Debug 构建及 Lint 通过（0 错误，16 项既有警告）。标准、小屏、150% 字号和横屏下的 28 行菜单可见内容左右留白差不超过 2 像素。Android 15 原生截图已确认边框与阴影效果；ColorOS 16 实机效果仍需用户覆盖安装确认。
