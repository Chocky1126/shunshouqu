# 顺手取 v1.7.9 已取件票据布局

按用户选定的第 3 套“轻量取件票据”布局更新已取件页。每张票据上方显示站点图标、名称和取件时间，中间为虚线与像素缺口，下方显示取件码及简短的“恢复”按钮。沿用现有站点图标和暖色配色。

标题、7 天保留说明及底部橙色“清空已取件”按钮固定，仅中间列表滚动。长站点名与取件码按需换行。恢复仍可选择现有站点；清空仍需确认。空历史不显示清空按钮。

包名 `cn.pickup.pocket`，versionCode 35，数据库 v5、引导版本和签名保持不变。不要先卸载或清除应用数据，直接覆盖安装。

验证：Debug/Release 各 15 项单元测试及 8 项历史与导航设备测试通过；Release Lint 为 0 错误、16 项既有警告。标准、小屏（360×640dp）、150% 系统字号及横屏（640×360dp）下检查了列表滚动、底部按钮位置及最旧记录的恢复入口。32 位长码完整换行、原站点删除后恢复、取消操作和清空均有回归覆盖。设计对照见根目录 `design-qa.md`。
