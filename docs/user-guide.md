# 顺手取 v1.7 使用指南

## 先设置站点

主页右上角 → 站点设置。选择名称和图标，按取件路线调整站点顺序。

格式中一个 `x` 代表一位数字，例如 `x-x-xxx` 对应 `2-1-003`。一个站点有多种格式时每行一种，例如 `x-x-xxx` 与 `xx-x-xxx`。不同站点不能设置相同格式。

## 录入

- **录入取件码**：输入一条，按格式自动归站。
- **旁边的上箭头**：选择批量录入、截图识别、扫描短信。识别结果需核对、勾选并保存；修改原文后请重新识别。
- **右上角 → 手动录入**：自行选择站点，适合预设格式之外的码。
- **分享给顺手取**：从其他应用分享短信文字或图片，进入核对页面。

截图可一次选最多 10 张。扫描短信需授权，只读取近 72 小时收件箱；待取和最近 7 天已取的码会跳过。识别可能有误，保存前请核对。没有剪贴板读取按钮，需要粘贴时使用输入框的系统粘贴。

## 取件

取件码在各站点内按每段数字从小到大排序，前导零保持原样。

左滑取件码或点右侧方框标记已取。**一键取出会取出全部站点的全部待取码**。点站点标题进入大字取件，逐条完成或跳过，可选择保持屏幕常亮。长按取件码可以编辑号码和所属站点。

## 恢复与清空

右上角 → 已取快递，可将最近 7 天的记录恢复到待取。原站点删除后，可以恢复到现有站点。清空已取件需确认，并会永久删除全部历史；不影响待取清单。

## 桌面与显示

右上角 → 更多设置 → 添加到桌面，先查看示例，再在系统弹窗中确认。也可使用桌面的普通小部件/插件列表添加顺手取。

4×4 小部件最多显示 6 条码，缩小时减少显示行并提示剩余数量。方框完成一件，一键取出完成全部待取。

更多设置可调整字号、行距和放置天数提示，也可在底部独立的“帮助”区域再次查看整个应用的使用引导。页面较长时只滚动中间内容。

数据保存在手机本地，卸载或清除数据会删除记录。升级时直接覆盖安装，不要先卸载或清除数据。
