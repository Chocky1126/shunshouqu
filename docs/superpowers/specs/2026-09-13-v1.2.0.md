# 顺手取 v1.2.0 升级设计

用户已同意实施全部优化。保持原生 Java、Android 8.0+、本机数据、原签名覆盖更新；版本 1.2.0 / code 4。

1. 批量录入：粘贴短信或多行取件码，从完整数字片段提取候选，避免从手机号/单号截取局部数字。显示候选码、站点和重复提示；用户勾选确认后事务保存。单条录入保持现有入口。
2. 取件模式：点击站点进入大字逐件视图，按数值顺序展示；已取后切到下一条，可跳过，可选择常亮。退出/后台释放常亮；完成后显示已取完。
3. 已取件：左滑和已取按钮均归档，保留最近 7 天，支持恢复；站点删除后保留历史名称，可选现有站点恢复。原有即时撤销继续支持。
4. 站点顺序：设置中长按拖动排序，提供上移/下移按钮辅助；顺序重启后保留。主界面空站点默认折叠，可展开。
5. 编辑：长按取件码修改，支持手动选择站点；仍只允许 1–32 字符数字和连字符结构，保留前导零和重复约束。已有记录修改保留录入时间。
6. 备份：系统文件选择器导出/导入 JSON，包含站点格式顺序、待取件、7 天内历史和提醒天数。导入先完整验证并显示数量，再由用户确认替换；损坏/未知版本/重复数据拒绝，事务失败不改变原数据。
7. 截图识别：系统选择图片，内置 ML Kit 中文模型离线识别，结果进入相同的可编辑批量预览，绝不直接保存识别结果。处理失败允许重选或粘贴文本。
8. 放置天数：本地日历日期计算“今天录入/已放 N 天”，默认 3 天突出提醒，可设 1–30 天；应用内提示，不新增后台通知。

不读取短信、通讯录或整个相册。图像仅本机识别；移除依赖合并进来的网络权限。支持旋转保留新界面草稿/状态，异步识别不向已销毁 Activity 更新界面。
