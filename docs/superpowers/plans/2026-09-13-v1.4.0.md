# 顺手取 v1.4.0 Implementation Plan

**Goal:** 实现分享录入、前台剪贴板自动识别、桌面小组件、每日定时提醒、多图识别。
**Architecture:** 原生 Activity + RemoteViews + AlarmManager；继续共用 BatchParser 与离线 OCR，识别后统一核对保存。数据库保持 v4；设备专属通知与剪贴板偏好独立存储，不随取件数据备份导入覆盖。
**Tech Stack:** Java 17, Android API 26–35, 已有 ML Kit 中文离线识别。

## 约束
- 用户已明确授权实现五项功能，直接在当前隔离工作目录内顺序实施。
- 不新增网络、短信或全盘存储权限。通知需要 Android 13+ 运行时授权；增加开机重排提醒接收器。
- 提醒默认关闭、默认时间 18:00；每日一次有件才通知，系统省电可能延后，无精确闹钟特殊权限。
- 剪贴板默认开启，仅主页获得窗口焦点时读取文本；匹配到未录入码才提示；同一剪贴板内容不重复提示，可关闭。敏感剪贴板跳过。
- 分享与图片选择最多 10 张，顺序识别、合并去重、显示进度与失败数量；不自动写入数据库。合并文字上限 100000 字符。
- 小组件默认仅件数及前 3 个有待取件的站点，支持站点点击、录入入口、数据变更刷新；不展示完整码。
