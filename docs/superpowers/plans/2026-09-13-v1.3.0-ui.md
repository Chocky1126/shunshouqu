# 顺手取 v1.3.0 · 视觉升级

用户要求：优化界面、UI 与动效。继续保留既有本地数据、识别规则、数字排序和全部取件功能。

1. 统一暖白背景、墨绿主色、橙色操作强调；共享圆角、文字、按钮、输入框与弹窗样式。
2. 首页加入清晰的图标快捷入口，优化站点卡片、码字号及触控区域；首页不显示识别格式。
3. 取件模式使用深色大字卡，突出主操作；批量核对、历史和设置补齐分组层次。
4. 页面轻量淡入上移、按钮涟漪与按压、滑动回弹及轻触觉反馈；遵循系统关闭动画的设置。
5. 回归所有现有测试；模拟器验证覆盖升级、滑动、旋转、大字体和实际界面；生成 APK、源码和截图。

技术边界：原生 Android View，不增加运行时依赖，不修改数据库结构；使用 Google Material Icons 官方资源并附许可证。
