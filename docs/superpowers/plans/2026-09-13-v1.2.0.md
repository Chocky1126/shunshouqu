# 顺手取 v1.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax.

**Goal:** 完成已确认的八项体验升级并交付可覆盖安装的 APK。
**Architecture:** 保留原生 Activity 和 SQLite，新增独立批量提取类、功能页面 Activity、截图识别类；存储层统一事务和备份校验。
**Tech Stack:** Java 17, Android SDK 35/min26, Gradle 8.11.1, AGP 8.9.2, ML Kit Chinese bundled 16.0.1。
**Spec:** ../specs/2026-09-13-v1.2.0.md

## Global Constraints
- 包名 cn.pickup.pocket；版本 1.2.0/code4；原签名。
- 保留旧版数据和现有功能，全部自动排序保留前导零。
- 截图/批量识别必须人工核对；导入替换必须应用内确认。
- 不申请短信/存储/网络权限；测试只使用专用模拟器。

### Task 1: 数据、历史和备份
**Files:** ParcelStore.java, Station.java, HistoryEntry.java, BackupSummary.java；StoreV4Test.java, 原迁移测试。
**Interfaces:** 沿用 all/add/delete/restore/stations；新增 addManual(String,int), updateParcel(long,String,int), history(), restoreHistory(long,int), reorderStations(List<Integer>), reminderDays(), setReminderDays(int), backupJson(), validateBackup(String), importBackup(String), addBatch(List<String>)。
- [x] 测试：旧 v1/v2/v3 升 v4 保留字段；删除入历史、7 天过期、恢复冲突不丢失；顺序持久化；非法备份无副作用；有效备份往返。
- [x] 实现：history 存储站点名称快照，无站点外键；归档与删除同一事务；数据库 v4 新增站点顺序和设置；备份完整校验后同一事务替换。
- [x] 验证：testDebugUnitTest 和 connectedDebugAndroidTest 的存储测试；审查事务、ID 和边界。

### Task 2: 批量提取和截图识别
**Files:** BatchParser.java, ScreenshotRecognizer.java, app/build.gradle, AndroidManifest.xml, BatchParserTest.java, ScreenshotRecognitionTest.java。
**Interfaces:** BatchParser.extract(String,List<Station>) 返回去重候选字符串；不从更长数字/连字符片段截取。ScreenshotRecognizer 通过图片 URI 异步返回文本，复用批量页面。
- [x] 测试完整匹配、短信混合手机号、不规则片段、全角、多格式、重复；例如“取件 2-1-003 手机13800138000”仅提取2-1-003。
- [x] 实现完整 token 匹配与候选限制；加入内置中文模型；图片限定解码尺寸，失败提示。
- [x] 实际本地图片验证 OCR 数字和连字符提取；检查打包权限和模型可离线使用。
